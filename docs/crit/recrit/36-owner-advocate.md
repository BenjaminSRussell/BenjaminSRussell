## 2. Five-second test

**870 px, day.** A very large "Ben Russell" in a serif, an italic sentence under it, a cream chart with blue-ringed islands and small numbers, a compass. In five seconds: a person who makes charts, and the chart is of something he owns. The field line in the cartouche (CRAWL AND DATA INFRASTRUCTURE · PYTHON AND RUST) is ~7 px at this width and does not read in five seconds; the field arrives from the table in seconds 6–10. The caption's "One feature per public repository, area by commits" tells you what the islands are. Nobody would call him a Scrapy maintainer: SCRAPY HARBOR is one island of twenty-one.

**360 px.** The phone hero carries name, thesis in two lines, the rose, Profile Shoal, Scrapy Harbor with two lit marks, and a cartouche that is actually legible: THE OPEN WEB · FROM SURVEYS 2025–2026 / CRAWL AND DATA INFRASTRUCTURE · PYTHON AND RUST / CHART NO. 21 · EDITION 0.1.3 · NOTICE 9. The phone reads the field *faster* than the desktop does. Then: a 48 px instruments strip that says only "CHART NO. 21 · SHEET 5" (sheets/instruments-phone.png), and no footer.

**Night.** The same reading, with the lights doing what the colophon promised. The name is the brightest text; the two lit marks are the brightest things. It is designed, not inverted.

**What the page says about the person.** Someone careful, with a thesis, who measures himself and prints the measurement even when it is unflattering (typical week 0; HW on a browser-game week). Who is visible: the name, the thesis, "I care how the work looks for the same reason I care that it holds", "These five I had to be told". Who signs the work: `SUPERINTENDENCE: BUILD_ASSETS.PY` on the hero imprint and "watch kept by cron" on the log. The only human signature on the page, *B.S.R.*, is on the one sheet whose figures were not observed.

## 3. Top five defects

### 1. The footer was swallowed by the Colophon; the page ends on a collapsed `<details>`
- **Where.** README.md Colophon, "Editions" bullet: `…picks the edition through \`<!-- picture:footer:start --><picture>…`; readme-light.png bottom (y≈4930): last visible line is "▸ Colophon · how the sheets are drawn…", nothing below. readme-light.html tail confirms the footer `<picture>` sits inside the `<li>`, `<!-- picture:footer:end -->` is doubled, `</details>` never closes.
- **Cause.** `scripts/render_readme.py` `migrate_pictures()` (`_PICTURE_RE = r"<picture>.*?</picture>"`, re.S) matched from the backticked literal `` `<picture>` `` in the Editions bullet to the real footer's `</picture>`, wrapped that span as the footer block, and `fill_block` then overwrote it, deleting the Motion, Variation, Figures, Build and License bullets that T8-README.final.md lines 162–170 specify.
- **Why it matters.** STANDARDS thesis: "the footer is where the water finally goes over the edge"; STD 7 (arc with a climax), STD 13 (the variation note "only resolves in the colophon"), J3, J12. Sheet 6 — "The chart ends here. The web doesn't." — is the exit line of the page and it is not on the page. The License bullet (CC BY 4.0, MIT) is gone, so the LICENSE-ASSETS.md work from BEN-TODO 3 is invisible. The one prose sentence that told a reader "italic numerals are not measured" is gone, which turns the log into a plain claim (defect 2).
- **Fix.** (a) `_PICTURE_RE = re.compile(r"(?<!`)<picture>\s*<source.*?</picture>", re.S)` so a backticked literal cannot start a match. (b) Restore the Colophon from T8-README.final.md 162–170 (Editions bullet ends "…finished and still."), close `</details>`, then `<!-- picture:footer:start -->…<!-- picture:footer:end -->` as the last block of the file, nothing after it (T8 decision 9). (c) check.py: fail if `count("<details>") != count("</details>")`, if any `picture:*:start` marker occurs inside a `<details>`, or if the footer picture is not the last block. Add one regression test with a backticked `<picture>` in the fixture.
- **Cost.** S.
- **Status while this was written.** README.md on disk was repaired mid-review (Colophon bullets back, `</details>` closed, footer block last). The judged render (`<qa>/readme/*.png`) still shows the swallowed footer, so the scores above stand for what was rendered. The repair is to the README text only: `migrate_pictures()` still matches a backticked `<picture>`, and check.py still has no rule for it, so the next `render_readme.py` run against a Colophon that mentions `<picture>` will do it again. Items (a) and (c) of the fix are still owed; re-render and re-judge J3/J12 after.

### 2. The Ship's log asserts a run that did not happen, and Ben signs it

A hiring manager who runs `pip install rustmapper` against a 12k-URL site and does not get 2.0 req/s and 0.4 % failures has caught Ben in a claim. His initials are on it. This is the one thing on the page he could not defend if asked "when did you run this?"
- **Fix.** Until BEN-TODO 7 lands: lede "The log as rustmapper keeps it, worked from the vessel's defaults against a local host; a recorded session will set the figures upright." Sheet: emit *B.S.R.* and "Log closed" only when `log.measured` is true; when false the closing line is "Worked, not observed · 1550" in the same italic. check.py: fail if `log.measured` is false and the README log lede matches `\bOne .* run\b`. - **Cost.** S for the build; M for Ben (one recorded session on a domain he controls, 20 minutes, then everything goes upright by itself).
