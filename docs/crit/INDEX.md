# Crit archive — how this chart was workshopped

Two panels reviewed the profile before the rebuild, then a technical team turned the findings into one plan.

- `BRIEF.md` — the facts about Ben and the hard constraints every reviewer worked under.
- `01–06` — the first panel: editorial designer, cartographer, hiring manager, writer-editor, motion designer, skeptic.
- `STANDARDS.md`, `CHANGELIST.md` — synthesis of the first panel into testable standards and a ranked change list.
- `specs/` — concept specs for the hero, the Approaches sheet, the supporting sheets, and the copy draft.
- `CRIT2-BRIEF.md`, `panel30/07–36` — the second panel of thirty: type designer, information designer,
  accessibility, mobile, GitHub platform, performance, cartography historian, printmaker, color scientist,
  narrative designer, brand strategist, recruiter, Rust engineer, data engineer, SRE, crawling expert,
  OSS maintainer, poet, comedy writer, sailor, exhibition designer, art director, UX researcher, design
  systems, illustrator, data journalist, design educator, philosopher, profile curator, owner's advocate.
- `TECH-BRIEF.md`, `tech/T1–T10` — the ten technical leads' sections; `tech/MASTERPLAN.md` — the integrated, decision-logged build plan (read this first).

Each review ends with its five most important lines; the technical team read those first.
