## 3. What must change

1. **The footer understates the agents** (page-phone-5). "63 commits carry an AI co-author trailer" is the smallest true number: stats.json also has 172 commits authored by Claude and 125 by jules, silently left out of "author's commits". On Rust-sitemap Claude has 45 commits to his 87. If I find that myself, the page lied by omission. Fix, from `others` and `coauthored_total.agent`: `… excluded · 297 commits by coding agents (Claude 172, jules 125) not counted; 63 of his carry a Claude co-author trailer.`
2. **"3 test files" is wrong for Rust by construction** (page-desk-1). tree.py counts only `.rs` under `tests/`; Rust unit tests live inline in `#[cfg(test)]`. The flagship reads as 16k lines, 3 tests. Fix: count `#[test]`/`#[tokio::test]` attributes for Rust and `def test_` for Python; print `N tests` on both lines.
3. **Jargon at two seconds** (sheet-phone-day-390, lines 4–5). `AUTHOR'S COMMITS · SWEEP DAYS EXCLUDED` makes a stranger ask what a sweep is. Fix: the sheet reads `21 REPOSITORIES · DATUM: MAIN · 9 OCT 2026 · EASTERN TIME`; the footer defines the rest. Cut the centred HTML role line under the image (page-phone-1); it repeats the sheet word for word.
4. **The rows don't read as data** (sheet-desk-day-870). Banks are 6–12 px tall in a 42 px pitch; thickness never visibly varies, so it is the Gantt chart in a costume D1 said it would avoid. Fix: scale so the busiest month of any row (Scrapy, Oct 2025) fills 80 % of the pitch; set the 5- and 10-day contour tints at 0.25 and 0.5 opacity so they show. Then the coast reads as coast, and that is the screenshot. Give every named row its language from `lines` (C, TypeScript, JavaScript), not two of seven.
5. **Housekeeping drawn as work** (sheet-phone-day-390). Row 4 is BENJAMINSRUSSELL, the README itself, above game_engine; and 7 rows plus `9 MORE` is not 21. Fix: merge the profile repository into the last row, lettered `14 MORE` (counting the five sweep-only repositories). Cut `Generated from my repositories by scripts/build_assets.py`: the standing rules ban "generated by" footers.
