**Hi, I'm Ben.** I'm a full-stack developer who keeps sailing into the same waters: the stretch between a page that lies and a row you can trust. The open web is badly charted. Pages drift, encodings shoal, sitemaps are wrong about themselves. Most of what I build is survey work. Crawlers that take soundings at scale and stay afloat when the site changes. Storage that keeps the log so any depth can be re-sounded. Instruments that show you where the vessel is *before* it finds the rocks.

I care about how things look the way I care about how they hold up. A chart nobody can read is not a chart. So this page is drawn, not templated: every sheet below is generated from one design system, in a day edition and a night edition, with real typefaces set as outlines. If the surface is confusing, the system underneath usually is too.

## Approaches

Two harbors I keep returning to. One is the platform, the other is the engine.

<a href="https://github.com/BenjaminSRussell/Scrapy"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/BenjaminSRussell/BenjaminSRussell/main/assets/approach-scrapy-dark.svg"><img src="https://raw.githubusercontent.com/BenjaminSRussell/BenjaminSRussell/main/assets/approach-scrapy-light.svg" width="100%" alt="Sheet 3, Approaches: Scrapy Harbor. **[Scrapy](https://github.com/BenjaminSRussell/Scrapy)** is the harbor with the lights on. A multi-stage crawler platform that discovers, analyzes and summarizes web content at scale, built to be operated rather than demoed.

- A scout spider with URL prioritization, JS-heavy page detection and adaptive, domain-aware rate limits
- Raw data lands in Delta Lake, metrics in PostgreSQL, queues in Redis, behind one storage interface
- Circuit breakers, health checks and live Grafana dashboards on Prometheus metrics, so the lights are on before anything goes wrong
- Typed configuration, 90%+ test coverage, Docker and Kubernetes manifests, one command to start

<br>

<a href="https://github.com/BenjaminSRussell/Rust-sitemap"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/BenjaminSRussell/BenjaminSRussell/main/assets/survey-rustmapper-dark.svg"><img src="https://raw.githubusercontent.com/BenjaminSRussell/BenjaminSRussell/main/assets/survey-rustmapper-light.svg" width="100%" alt="Sheet 4, Surveys: Rustmapper Shoal. **[rustmapper](https://github.com/BenjaminSRussell/Rust-sitemap)** is the survey vessel. A concurrent sitemap crawler and URL discovery tool written in Rust and shipped as a Python package, so the fast path is one `pip install` away.

- Up to 512 workers with adaptive concurrency control and a sharded frontier
- Persistent state behind a write-ahead log, so a crawl can be stopped and resumed where it left off
- Seeds from sitemaps, Certificate Transparency logs and the Common Crawl index, which is how you find the subdomains nobody links to
- Optional Redis for distributed runs, a native Rust CLI, a Python API via maturin, published on [PyPI](https://pypi.org/project/rustmapper/)

## Notes to mariners

Five rules I keep relearning, written down so I stop relearning them.

1. **Boring under load.** The interesting version of a system is the one still running on day forty. Clever is for prototypes.
2. **Keep the log.** Raw before clean, always. The question you will want to answer next month is one you cannot imagine today.
3. **Lights before speed.** A crawler you cannot watch is a crawler you cannot trust. Dashboards and breakers belong in version one, not in the polish.
4. **Charts over heroics.** Clear data shapes beat clever parsing. My golden rule for URLs: never regex what a parser already understands.
5. **The surface is part of the system.** If the tool is ugly it is probably also confusing, and confusion is an operational cost.

## Colophon

This page is drawn, not templated, and it is built the way I build everything else.

- **Type.** Instrument Serif for titles and the italic asides, IBM Plex Mono for chart labels and the log. Set as outlines inside every SVG, so it looks the same on every machine.
- **Chart.** The bathymetry is a scalar field traced with marching squares and smoothed into Béziers. Islands are named after the projects. Soundings keep clear of the plotted course. The compass points to the accent.
- **Color.** Navy ink on cream paper by day, a red-light-safe night chart after dark, and your system setting picks the edition through `<picture>`. Red cans and green cones are the only other colors, because that is what the lateral marks are.
- **Motion.** SMIL only, slow and purposeful. A boat sails the course, a packet runs the channel, soundings fill in, a light sweeps the harbor, the log types itself.
- **Build.** `scripts/build_assets.py` draws every sheet; `scripts/build_stats.py` takes the day's soundings from GitHub and a workflow refreshes them each morning. Tokens and rules are in [DESIGN.md](DESIGN.md).

If you like it, borrow it. Change the name, the copy and the palette, and the chart is yours.

<br>

**Off the clock.** The avatar is a sailboat about to go over a waterfall at golden hour. I'm told that's a mood. Mostly it's a reminder that the view is best right before the drop, and that it pays to have checked the chart.
