### What I build

I write the unglamorous layer that keeps data moving: **scrapers that survive site changes**, **pipelines that don't silently rot**, and **small systems in Python and Rust** that stay up when nobody is watching.

Most of the work lives between "fetch" and "trust" — retry logic, schema drift, rate limits, messy HTML, sitemap graphs, and the glue that turns a crawl into something you can query tomorrow.

Right now that means:

- **[Scrapy](https://github.com/BenjaminSRussell/Scrapy)** — a scraping / data platform: spiders, orchestration, and the dashboard that shows whether the field is healthy
- **[Rust-sitemap](https://github.com/BenjaminSRussell/Rust-sitemap)** — fast sitemap discovery and structure work where Python gets expensive

I care about clarity under load: logs you can read, failures you can replay, and interfaces that tell the truth when metrics are missing.
